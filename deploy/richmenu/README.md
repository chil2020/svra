# 圖文選單

選單是在 **LINE 官方帳號後台**建的，不是用 API（決策 33）。
所以**LINE 那一側的設定不在版控裡**——這個目錄是唯一補得回來的部分：
圖、產生圖的程式，以及下面這份「後台該填什麼」。

改動任何一項時，這份文件要一起改。

## 後台怎麼設

**https://manager.line.biz/** → 選 SVRA（`@760vatty`）→ 左側**聊天室相關 → 圖文選單** → 建立

### ⚠️ 不要走進「圖文訊息」

後台有兩個長得很像的功能，而它們完全不同：

| | 是什麼 | 尺寸 | 費用 |
|---|---|---|---|
| **圖文選單** Rich Menu | 聊天室下方**常駐**的選單 | 2500×1686 或 **2500×843** | 免費 |
| 圖文訊息 Rich Message | 主動**推播**出去的一則圖片訊息 | 1040×1040 等 | **吃額度** |

走錯的症狀很好認：**版型對話框出現 `1040px` 與「正方形／橫長／縱長」就是走錯了**，
圖文選單那邊只會有「大型／小型」與 2500px。

| 欄位 | 值 |
|---|---|
| 標題 | SVRA 常用 |
| 使用期間 | 開始日填今天，結束日留空 |
| 選單列文字 | `選單` |
| 預設顯示 | **收合**（不要勾「顯示」） |
| 版型 | **小型**（2500×843）→ 一列三格 |
| 圖片 | `svra-richmenu.png`（2500×843，正好是小型的尺寸） |

### 三個動作區

| 區塊 | 類型 | 內容 |
|---|---|---|
| 左 | 文字 | `列出行程` |
| 中 | 連結 | `https://calendar.google.com/?openExternalBrowser=1` |
| 右 | 文字 | `使用說明` |

## 🔴 兩個字串必須跟程式碼一致

`列出行程` 與 `使用說明` 同時存在於**兩個地方**：這裡（後台），
以及 `io.svra.command.QuickCommand`。

後台改了字而程式碼沒跟著改，**症狀不是壞掉**——按鈕會靜靜地掉回 LLM 解析，
多半仍然做對事，只是慢、而且偶爾解錯。**不會有人發現。**

## 🔴 連結那顆的 `openExternalBrowser=1` 不能拿掉

Google 在內嵌 webview 裡擋登入，而 LINE 的瀏覽器沒有使用者的 Google session。
拿掉的話，多數人按下去會看到一片要登入卻登不了的畫面——
跟決策 27 那個 `disallowed_useragent` 是同一個坑。

## 重新產生圖

```bash
cd deploy/richmenu && swift render.swift
```

macOS 內建的 CoreGraphics + CoreText，不需要裝任何東西。
配色取自專案既有的 tokens（`--accent: #2C6A57`）。

## 點擊統計

後台 → 分析 → 圖文選單。可選 60 天、能下載 Excel。
**這是後台建選單附帶的好處**，API 建的沒有。
